# Hold Still

*A horror game where your body is the controller and your room is the map. No weapons. Just hold still.*

A mixed reality game for Meta Quest 3 / 3S, being built for the **Meta VR Start Developer Competition 2026** (Gaming track). Submission target: **Nov 16, 2026**.
